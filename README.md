# javascript-racingcar-precourse

### 기능 구현 목록

- [x] 안내메세지를 출력한다.
- [x] 자동차이름을 입력받는다
- [x] 자동차는 쉼표(,)로 구분한다.
- [x] 시도할 횟수를 입력 받는다.
- [] 자동차의 이름에 공백이 포함된다면 제거한다.
- [] 각 자동차가 무작위 값이 4이상이라면 전진한다.
- [] 자동차들의 거리를 계산한다.
- [] 우승자를 출력한다.(우승자가 여러명일 경우 ,(쉼표)를 이용하여 구분)

### 예외처리

- [] 자동차의 이름은 5자 초과일 경우
- [] 시도할 횟수가 숫자가 아닌 경우
