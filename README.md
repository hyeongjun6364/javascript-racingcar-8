# javascript-racingcar-precourse

### 기능 구현 목록

1. 사용자 입력

- [x] 사용자에게 n대의 자동차이름 입력을 받는다.
- [x] 자동차의 이름은 쉼표(,)로 구분한다.(공백은 trim으로 제거)
- [x] 시도 횟수를 입력받는다.

2. 자동차 전진 조건

- [x] 0~9사이에 무작위 값을 각각 구한다.
- [x] 숫자가 4 이상이면 전진하도록 한다.

3. 우승자 선정

- [x] 가장 많은 거리를 간 자동차를 배열로 반환한다.

3. 게임 결과 출력

- [x] 시도횟수동안 전진을 하게되면 (-)을 출력하게 한다.
- [x] 시도횟수가 다 끝났다면 게임을 종료하고 우승자를 출력한다.(복수일 경우 쉼표(,)를 이용하여 구분)

### 예외처리

1. 자동차 입력

- [x] 자동차의 이름이 1자이상 5자 미만이 아닐 경우
- [x] 자동차의 이름이 중복된 경우가 있을 경우
- [x] 자동차가 2개 미만인 경우
- [x] 자동차 이름이 빈 문자열일 경우

2. 시도할 횟수 입력

- [x] 시도할 횟수가 숫자가 아닌 경우
- [x] 시도할 횟수는 1이상 30 이하여야 한다.

### 유효성 테스트

- [x] 자동차의 이름이 1자이상 5자 미만이 아닐 경우
- [x] 자동차의 이름이 중복된 경우가 있을 경우
- [x] 자동차가 2개 미만인 경우
- [x] 자동차 이름이 빈 문자열일 경우
- [x] 시도할 횟수가 숫자가 아닌 경우
- [x] 시도할 횟수는 1이상 30 이하여야 한다.
- [x] 자동차이름 성공 케이스 테스트
- [x] 시도할 횟수 성공 케이스 테스트

### 기능 테스트

1. 자동차 전진 조건 테스트

- [x] 자동차가 4 이상이면 전진한다.
- [x] 자동차가 3 이하면 정지한다.

2. 우승자 선정 로직 테스트

- [x] 가장 멀리간 자동차의 이름을 반환한다.
- [x] 공동 우승자가 있는 이름들을 반환한다.
